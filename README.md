# Template — Espace client / Programmation seule

Page client réutilisable, aux couleurs de la charte DA Evan Merioua Coaching.

## Pour un nouveau client
1. Duplique le dossier (`index.html` + `assets/`).
2. Dans `index.html`, remplis uniquement le bloc `PROGRAMME` (dans la balise `<script>` en bas) :
   prénom, dates, analyse morpho (bas du corps / haut du corps / dos), choix du split,
   structure, focus, séances et exercices, évolutions à venir.
3. Glisse le dossier sur Netlify (Deploy manually).

Commun à tous les clients (à ne pas toucher) : correction technique vidéo, signes pour retirer/ajouter une série,
« Dans la durée », toute la partie 03 « Progresser en autonomie », et l'encart DM « PRÉPA ».
Le carnet de charges sous chaque séance est enregistré dans le navigateur du client.
