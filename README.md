# Template — Programmation seule

Page client réutilisable (charte DA Evan Merioua Coaching).

## Pour un nouveau client
1. Duplique le dossier (`index.html` + `assets/`).
2. Dans `index.html`, remplis uniquement le bloc `PROGRAMME` (dans la balise `<script>`) : prénom, objectif, durée, semaine type, séances et exercices.
3. Glisse le dossier sur Netlify (Deploy manually).

Tout le reste (méthode de progression, RIR, faire évoluer le programme, FAQ, CTA « PRÉPA ») est commun à tous les clients.
Le carnet de charges est enregistré dans le navigateur du client.
